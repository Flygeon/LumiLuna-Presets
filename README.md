# LumiLuna 音效预设共享仓库

欢迎！本仓库收录了 LumiLuna 播放器用户分享的音效预设（EQ/低音/混响/立体声配置）。

## 如何提交你的预设

1. **Fork** 本仓库
2. 在 `presets/` 目录下新增一个 JSON 文件，命名格式：`preset-<英文名>.json`
3. 按照下方 JSON 格式填写你的预设
4. 发起 **Pull Request**
5. 维护者审核后合并

## JSON 预设格式

```json
{
  "name": "预设名称（中文/英文均可）",
  "version": 1,
  "description": "一句话描述这个预设的特点和适用场景",
  "shareCode": "LLFX3:xxx"
}
```

| 字段 | 说明 |
|------|------|
| `name` | 预设名称，建议 2-12 字 |
| `version` | 版本号，目前固定为 `1` |
| `description` | 预设描述，说明风格、适用音乐类型等 |
| `shareCode` | 分享码，从 LumiLuna 应用内「音效设置 → 分享预设」复制 |

## 如何获取分享码

1. 在 LumiLuna 中调整好你的音效参数（EQ / 低音 / 混响 / 立体声宽度）
2. 点击「保存预设」→ 输入预设名称
3. 在预设列表中找到它，点击「分享」按钮
4. 分享码会自动复制到剪贴板（格式如 `LLFX3:xxx`）

## 审核标准

- 预设名称、描述完整
- 分享码格式正确，能正常导入
- 参数不极端（如所有 EQ 增益不超过 ±12，混响/立体声宽度 0-100）
